## 1. 개요
작업장(Work Center) 정보는 제조 공정에서 실질적으로 작업을 수행하는 장소(설비 라인 또는 작업 셀)를 정의하고, 공정별 Capa(생산능력) 및 표준 가동시간 계산의 기초를 제공하는 기준 마스터 정보입니다. 기존의 복잡한 연산 부속 필드들을 정리하고 대표공정 연동 및 가동 시간 계산에 핵심이 되는 필드 위주로 구성을 슬림화합니다.

## 2. 데이터베이스 설계안 (WCI_MT)
대표공정 연동 시 대원칙을 준수하여 공용코드 테이블의 정수형 일련번호(`ProcessIndex`)를 FK로 매핑합니다.
| 컬럼명 | 데이터 타입 | Null 여부 | 속성 및 용도 |
|---|---|---|---|
| `Index` | `INT` | NOT NULL | 고유 식별 일련번호 (PK, AUTO_INCREMENT) |
| `WCName` | `VARCHAR(255)` | NOT NULL | 작업장 명칭 (내용키, 식별자) |
| `ProcessIndex` | `INT` | NOT NULL | 대표공정 인덱스 식별자 (FK, 공용코드 테이블의 Index 참조) |
| `WorkerCount` | `INT` | NOT NULL | 작업장 소속 보유 인원수 (기본값 1) |
| `CapaDivision` | `VARCHAR(100)` | NOT NULL | Capa 계산 구분 ('작업시간', '작업시간*인원') |
| `OperatingTime` | `INT` | NOT NULL | 표준 일일 가동 시간 (분 단위, 기본값 480) |
| `RecodingState` | `TINYINT(1)` | NOT NULL | 레코드 제어 상태 (소프트 삭제용 플래그, 기본값 1) |
| `RegistrationPerson` | `VARCHAR(255)` | NOT NULL | 등록자 |
| `RegistrationDate` | `DATETIME` | NOT NULL | 등록일시 |
| `UpdatingPerson` | `VARCHAR(255)` | NULL | 수정자 |
| `UpdatingDate` | `DATETIME` | NULL | 수정일시 |

## 3. 비즈니스 로직 및 제약 사항

### 3.1. 내용키 고유성 및 유효 데이터 매핑 검증
- 3.1.1. **작업장명 중복 검사:** 신규 작업장을 등록하거나 기존 작업장 명칭을 수정할 때, 소프트 삭제되지 않은 유효한 데이터(`RecodingState = 1`) 중에서 동일한 작업장명(`WCName`)이 존재하지 않는지 사전 유효성 검증을 수행합니다.
- 3.1.2. **대표공정 유효성 검사:** 화면 단 콤보박스에서 선택되어 넘어온 `ProcessIndex` 값은 공용코드(`PUC_MT`) 테이블 내에서 `RecodingState = 1`이며 대분류가 '공정'인 소분류 인덱스 코드여야 합니다.

### 3.2. Capa(생산능력) 및 작업량 계산 모델
실질 작업량(생산 한계량) 계산을 위해 백엔드 계산 엔진에서 다음 수식을 참조합니다.
- 3.2.1. **'작업시간' 구분일 때:** `총생산Capa = 일일 가동시간(OperatingTime)`
- 3.2.2. **'작업시간*인원' 구분일 때 (확장용):** `총생산Capa = 일일 가동시간(OperatingTime) * 보유인원(WorkerCount)` (현재 사용자 화면에서는 폼에서 숨겨두며, 데이터 저장 시 기본적으로 '작업시간' 값으로 우선 적용 및 세팅되도록 처리합니다.)

## 4. 화면 (UI/UX) 구성안 (표준 2분할 레이아웃)
- 4.1. **좌측 영역 (작업장 탐색 리스트 Grid):**
  - 작업장명 검색 조건과 리스트 테이블을 제공합니다.
  - 그리드에는 작업장명, 대표공정명, 보유인원, 일일가동시간을 표시합니다.
- 4.2. **우측 영역 (상세 및 등록/수정 폼):**
  - 상단에 신규등록, 저장, 삭제 버튼을 노출시킵니다.
  - 필수 입력 필드: 작업장명, 대표공정(공용코드 연동 콤보박스), 보유인원, 가동시간(분) 입력을 일체화하여 배치합니다.
  - **Capa 구분 필드는 화면에서 노출하지 않고 숨김 처리**하되, 기본적으로 '작업시간' 조건으로 내부 지정되도록 설계합니다.
