## 1. 개요
단가정보(Unit Cost Info)는 기업의 구매(원자재 매입), 영업(완제품/상품 매출), 생산(임가공 외주) 프로세스 전반에 걸쳐 기준 단가를 적용하기 위한 기준 마스터 정보입니다. 기존 레거시의 파편화된 테이블 구조를 하나로 통합하여 `구매단가`, `판매단가`, `외주단가`를 단일 테이블(`UCI_MT`)에서 체계적으로 관리하며, 단가 변동 역사를 추적할 수 있도록 이력 관리 테이블(`UPUCI_HT`)을 연동합니다.

## 2. 데이터베이스 설계안 (UCI_MT / UPUCI_HT)
단가 구분 컬럼을 기준으로 대상 품목, 거래처, 외주용 시작/종료 공정 및 발주 비율을 복합적으로 제어하는 통합 DDL 스키마를 구성합니다.

### 2.1. 통합 단가 마스터 테이블 (UCI_MT)
| 컬럼명 | 데이터 타입 | Null 여부 | 속성 및 용도 |
|---|---|---|---|
| `Index` | `INT` | NOT NULL | 고유 식별 일련번호 (PK, AUTO_INCREMENT) |
| `UnitCostDivision` | `VARCHAR(100)` | NOT NULL | 단가 구분 ('구매단가', '판매단가', '외주단가') |
| `ItemIndex` | `INT` | NOT NULL | 대상 품목 식별 인덱스 (FK, II_MT 참조) |
| `CompanyIndex` | `INT` | NOT NULL | 매핑 거래처 식별 인덱스 (FK, CI_MT 참조) |
| `BeginProcessIndex` | `INT` | NULL | 외주 시작공정 식별 인덱스 (FK, 공용코드 PUC_MT 참조, 외주단가 전용) |
| `EndProcessIndex` | `INT` | NULL | 외주 종료공정 식별 인덱스 (FK, 공용코드 PUC_MT 참조, 외주단가 전용) |
| `StandardUnitCost` | `DECIMAL(19,4)` | NOT NULL | 기준 단가 (금액 데이터로 정밀 소수점 4자리 지원) |
| `DiscountUnitCost` | `DECIMAL(19,4)` | NOT NULL | 할인 단가 (기본값 0.0000) |
| `OrderRate` | `DECIMAL(5,2)` | NULL | 발주 비율 (%, 구매/외주 단가 전용, 기본값 0.00) |
| `BeginDate` | `DATETIME` | NOT NULL | 단가 적용 시작일 |
| `EndDate` | `DATETIME` | NULL | 단가 적용 종료일 |
| `UpdateReason` | `VARCHAR(255)` | NULL | 단가 변동/변경 사유 |
| `RecodingState` | `TINYINT(1)` | NOT NULL | 레코드 제어 상태 (소프트 삭제용 플래그, 기본값 1) |
| `RegistrationPerson` | `VARCHAR(255)` | NOT NULL | 등록자 |
| `RegistrationDate` | `DATETIME` | NOT NULL | 등록일시 |
| `UpdatingPerson` | `VARCHAR(255)` | NULL | 수정자 |
| `UpdatingDate` | `DATETIME` | NULL | 수정일시 |

### 2.2. 통합 단가 이력 테이블 (UPUCI_HT)
단가 계약의 변경 내역을 추적하기 위해 마스터 테이블과 1:N 관계로 매핑되며, 명세 구조는 마스터 테이블(`UCI_MT`)과 동일하고 마스터를 가리키는 `UnitCostInfoIndex` (FK)가 추가됩니다.

> [!important] 외래키(FK) 설계 원칙 준수
> - 모든 식별자 및 조인 대상은 테이블의 기본키(`Index`) 값만을 차용하여 무결성을 유지하며, 각 외래키 컬럼에 대해 개별 물리 인덱스(`INDEX`)를 생성하여 다중 조인 조회 성능을 보장합니다.

## 3. 핵심 비즈니스 로직 및 제약 사항

### 3.1. 단가 구분별 필수 제약 조건 및 비즈니스 매핑 규칙
단가 유형에 따라 시스템이 유효성을 검증하며, 적합하지 않은 품목 자산 분류나 누락된 필드가 있을 경우 등록을 제한합니다.
- 3.1.1. **구매단가 규칙:** 원자재 및 상품 품목에만 등록할 수 있습니다. 거래처(매입처) 매핑이 필수이며, 시작/종료 공정 필드는 무조건 NULL이어야 합니다. 동일 품목에 여러 구매처가 매핑되는 경우 발주 비율(`OrderRate`)을 필수로 입력해야 합니다.
- 3.1.2. **판매단가 규칙:** 제품 및 상품 품목에만 등록할 수 있습니다. 거래처(매출처/고객사) 매핑이 필수이며, 시작/종료 공정은 NULL이어야 합니다. 판매는 고객사 대상이므로 발주 비율 필드는 불필요(0.00으로 잠금)합니다.
- 3.1.3. **외주단가 규칙:** 자가 공정이 포함된 반제품 및 완제품 품목에만 등록할 수 있습니다. 임가공 협력사인 거래처(외주처) 매핑이 필수이며, 해당 임가공이 수행되는 구간인 **시작공정(`BeginProcessIndex`)과 종료공정(`EndProcessIndex`)을 필수로 매핑**해야 합니다. 동일 외주 공정에 여러 협력사가 참여할 수 있으므로 발주 비율(`OrderRate`) 입력이 필수입니다.

### 3.2. 발주 비율 기반 수량 분할 로직 (중요)
- 3.2.1. **자동 수량 배분:** 자재 소요량 계획(MRP) 또는 외주 발주 계획 수립 단계에서 시스템은 활성화된 단가 기준 정보에 매핑된 거래처와 발주 비율(`OrderRate`)을 읽어옵니다.
- 3.2.2. **예시 시나리오:** A 원자재에 대해 매입 거래처 B사(비율 60%), C사(비율 40%), D사(비율 0%)가 등록되어 있고, 시스템에서 1,000개의 A 원자재 구매 발주 계획을 승인하는 경우.
  - 시스템은 비율이 유효한 B사와 C사 대상의 2개 구매요청 레코드만 자동 생성합니다.
    - `B 거래처` : 발주 수량 **600개** (1,000개 * 60%)
    - `C 거래처` : 발주 수량 **400개** (1,000개 * 40%)
- 3.2.3. **발주비율 0% 거래처 배제 규칙:** 단가 정보에 등록은 되어 있으나 발주 비율이 **0%**인 거래처(예: 위의 D사)는 실제 수량 분할 계산 결과가 0개가 되므로, **구매 요청 및 작업계획 수립 대상 레코드 생성 자체를 수행하지 않고 원천 배제**합니다.
> [!warning] 발주 비율 정합성 검증 메커니즘
> - **단가 등록/수정 시점 (100% 초과 차단):** 새로운 거래처의 단가를 순차적으로 등록할 때(예: B사 60% 먼저 등록 후 C사 40% 등록), 일시적인 100% 미만 상태는 허용해야 하므로 **100%를 초과하는 경우만 즉각 에러를 발생시키고 차단**합니다.
> - **발주 및 작업계획 확정 시점 (정확히 100% 검증):** 실제 구매 발주 요청이나 외주 작업계획을 수립하고 확정하는 트랜잭션 시점에는, 해당 품목에 매핑된 활성 단가들의 **발주 비율 총합이 정확히 100%인지 엄격하게 검증**합니다. 100%가 아닐 경우 일정 수립이나 발주서 발행 승인이 차단되어 데이터 유실을 방지합니다.
> - **백엔드 동시성 검증**: 동일 품목에 여러 사용자가 동시에 단가를 등록해 합계가 100%를 초과하는 정합성 예외를 막기 위해, 데이터 저장 시 백엔드 단에서 품목 ID 기준으로 **비관적 락(Pessimistic Lock)**을 적용해 정합성을 보장합니다.
## 4. 화면 (UI/UX) 구성안 (통합 2분할 레이아웃)
단가 구분 탭 구성을 통해 복잡한 입력 동선을 단순화합니다.
### 4.1. 좌측 영역 (단가 구분 탭 및 품목 리스트)
- 4.1.1. 상단에 `구매단가`, `판매단가`, `외주단가` 3대 탭 메뉴를 배치하여 사용자가 목적에 맞춰 선택하도록 유도합니다.
- 4.1.2. 그리드 목록에는 선택한 단가 유형별로 등록되어 있는 품목 및 거래처 요약 목록(품목코드, 품목명, 거래처명, 기준단가, 발주비율, 유효기간)이 조회됩니다.

### 4.2. 우측 영역 (상세 편집 및 이력 타임라인)
- 4.2.1. **단가 유형별 동적 필드 제어 (UX):**
  - **'구매단가' 선택 시:** 시작/종료 공정 드롭다운 비활성화, 발주 비율 필드 활성화.
  - **'판매단가' 선택 시:** 시작/종료 공정 드롭다운 비활성화, 발주 비율 필드 비활성화 및 0% 고정.
  - **'외주단가' 선택 시:** 시작/종료 공정 선택 드롭다운 활성화(필수), 발주 비율 필드 활성화.
- 4.2.2. **단가 변경 이력 타임라인:** 하단 영역에는 현재 선택된 품목-거래처의 과거 단가 계약 이력을 최근 적용일 순서대로 타임라인 그리드로 표출합니다. 단가가 수정될 때마다 사용자는 필수적으로 '변경 사유'를 입력해야 히스토리 관리가 가능합니다.
