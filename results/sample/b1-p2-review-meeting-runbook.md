## 2. 화면 시연 스크립트

### 품목구성 (10분)

1. `FG-01` BOM 목록 — SF-01, RM-PA, RM-PB
2. **정전개** — leaf 4 확인
3. **4필드 등록** 폼 (수정은 수량만)
4. 질문: 조달구분 PUC·4필드로 충분한가?

### 작업장 (7분)

1. `WC-Cut-01` — 주공정 절단(14000010), 가동 480분
2. 질문: 달력 복사 없이 Override만으로 운영 가능한가?

### 설비 (6분)

1. 등록 폼 6필드
2. 질문: Drop 필드(위치·단위) 이슈 없는가?

### 작업표준 (10분)

1. `FG-01` INHOUSE 공정 — worker01, setup/standard time
2. P0-1 작업일보와 연결 설명 (자동 대입은 Phase2)
3. 질문: 9필드·우선순위 1건으로 충분한가?

### 생산달력 (10분)

1. 기본 생산달력 화면
2. 작업장 Override (WC-Cut-01)
3. (선택) `e2e-calendar-capa.ps1` PASS 공유

### 사용자 (7분)

1. `worker04` — PURCHASE_OPERATOR
2. `worker08` — BASIS_MANAGER
3. 질문: 역할 기반 메뉴 제한 동의? 단축메뉴 Drop 동의?
