## 2. 화면 시연 스크립트

메뉴 경로: **기준정보** → 품목 / 공정 / 단가

### 2-1. 품목 (§E, 약 20분)

1. **목록** — 검색 `FG-01`  
   - 품번·품명·자산분류(제품)·단위·기준단가 확인  
2. **등록 폼** — 필드 개수·항목 나열 (11필드 슬림)  
   - **질문 E1:** 일상 등록에 충분한가?  
3. **자산분류** — `SF-01`(공정품), `RM-PA`(원자재) 각각 조회  
   - **질문 E2:** 반제품→공정품 명칭·4종 분류 동의?  
4. **재고 Lazy (설명)**  
   - 신규 품목은 재고 0; P0-1에서 입고·작업실적 후에만 증가  
   - **질문 E3:** 품목만 먼저 등록하는 업무 패턴인가?  
5. **Drop 필드** — 도면번호·재질·분류1~4 **화면 없음** 명시  
   - **질문 E4:** Cut-over 후에도 필수인 항목 있는가?

**시연 품목:** `FG-01` (제품), `RM-PA` (원자재, 공정 없음)

---

### 2-2. 공정 (§F, 약 20분)

1. **품목 선택** `FG-01` → 공정 계획 목록  
   - 순번 10·20 OUTSOURCE(용접·성형), 30 INHOUSE(절단)  
   - **질문 F4:** 자가/외주 구분이 현업 용어와 맞는가?  
2. **공정품** `SF-01` — 공정 2~3건, 외주 혼합  
   - **질문 F2:** 원자재 `RM-PA`에는 공정 등록 불가(또는 미사용) 확인  
3. **등록 Modal** — 입력 필드 7개만 노출  
   - **질문 F1:** 추가로 꼭 필요한 입력 항목?  
4. **WIP Lazy (설명)**  
   - 공정 등록 시 완료 공정 WIP만 자동; 외주 투입은 단가 등록 시  
   - **질문 F3:** 재고 행이 즉시 안 보여도 되는가?

**시연 품목:** `FG-01`, `SF-01`, 대조 `RM-PA`

---

### 2-3. 단가 (§G, 약 25분)

1. **판매 탭** — `FG-01` + `Sales-01` 1건 (품목당 거래처 1개)  
2. **구매 탭** — `RM-PA` + `Purchase-01`, 발주비율 **100%**  
   - 원자재 7종 각 1거래처 (Purchase-01~07)  
3. **외주 탭** — `FG-01`  
   - **공정당 1거래처**, 시작·종료 공정 동일(공정 단위), 발주비율 100%  
   - **질문 G2:** 외주만 공정 FK 필수 — 동의?  
4. **수정 시연** — 단가 1건 수정 → **변경사유** 입력·이력  
   - **질문 G3:** 사유 필수·이력 보관 동의?  
5. **외주 투입 창고 (설명)**  
   - 외주단가 등록 시 OUTSOURCE 투입 잔고 자동(Projector)  
   - Part06 E2E PASS 근거 공유  
   - **질문 G4:** 자동 생성 정책 동의?  
6. **3탭 통합**  
   - **질문 G1:** 레거시 3메뉴 → 단일 `unit_price` 탭 구조 동의?

**시연 품목:** `FG-01`, `RM-PA`
