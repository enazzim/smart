## 1. 개요
BOM(품목구성) 정보는 완제품 또는 반제품(모품목)을 생산하기 위해 어떤 원자재나 부품(자품목)이 어떤 비율로 소요되는지 정의하는 자재 소요량 명세 마스터 데이터입니다. 복잡한 버전 관리용 비즈니스 로직은 일단 배제하여 프로세스를 단순화하되, 장기적 유지보수와 기능 확장을 위해 데이터베이스 레벨에서는 적용 기간(시작일/종료일) 필드를 설계에 미리 반영해 둡니다.

## 2. 데이터베이스 설계안 (BOM_MT)
자산분류상 '제품', '반제품'만이 모품목이 될 수 있으며, '원자재', '반제품'이 자품목이 되는 구조적 제약 조건을 가집니다.
| 컬럼명 | 데이터 타입 | Null 여부 | 속성 및 용도 |
|---|---|---|---|
| `Index` | `INT` | NOT NULL | 고유 식별 일련번호 (PK, AUTO_INCREMENT) |
| `ParentItemIndex` | `INT` | NOT NULL | 모품목 인덱스 식별자 (FK, II_MT 참조) |
| `ChildItemIndex` | `INT` | NOT NULL | 자품목 인덱스 식별자 (FK, II_MT 참조) |
| `ParentQuantity` | `DECIMAL(19,4)` | NOT NULL | 모품목 기본 단위 수량 (소요량의 분모, 기본값 1) |
| `ChildQuantity` | `DECIMAL(19,4)` | NOT NULL | 자품목 소요 수량 (소요량의 분자) |
| `StartDate` | `DATETIME` | NULL | [확장용] BOM 적용 시작일 |
| `EndDate` | `DATETIME` | NULL | [확장용] BOM 적용 종료일 |
| `RecodingState` | `TINYINT(1)` | NOT NULL | 레코드 제어 상태 (소프트 삭제용 플래그, 기본값 1) |
| `RegistrationPerson` | `VARCHAR(255)` | NOT NULL | 등록자 |
| `RegistrationDate` | `DATETIME` | NOT NULL | 등록일시 |
| `UpdatingPerson` | `VARCHAR(255)` | NULL | 수정자 |
| `UpdatingDate` | `DATETIME` | NULL | 수정일시 |

> [!tip] 소요량 계산 방식 (분수식 적용)
> 자품목 1단위 생산을 정의하기 어려운 경우(예: 화학 배합이나 대량 사출 시 모품목 100개 기준 자품목 5kg 소요 등)를 대비하여, `ChildQuantity / ParentQuantity` 형태의 분수식 소요량 계산 모델을 지원하여 현업 유연성을 높입니다.

## 3. 비즈니스 로직 및 제약 사항

### 3.1. 무한 루프 검증 (Circular Reference Prevention)
- 3.1.1. **제약 사항:** BOM 등록 시 모품목이 자기 자신을 자품목으로 등록하거나, 자품목의 하위 BOM 구조에 상위 모품목이 다시 포함되는 순환 참조(무한 루프)[^1] 현상이 발생해서는 안 됩니다.
- 3.1.2. **검증 로직:** 자품목을 추가할 때, 백엔드 서비스 단에서 재귀 쿼리나 DFS(깊이 우선 탐색) 알고리즘을 수행하여 새로 매핑될 구조 내에 상위 모품목이 존재하는지 사전 검증 후 트랜잭션을 승인합니다.

### 3.2. 등록, 수정, 삭제 프로세스
- 3.2.1. **등록:** 모품목과 자품목을 매핑하고 소요량 분자/분모 값을 입력하여 등록합니다. 확장용 시작일/종료일은 기본적으로 현재 시각 또는 무제한(9999-12-31)으로 자동 기입되도록 세팅합니다.
- 3.2.2. **수정:** 특정 자품목의 소요 수량을 수정할 때, 기존 이력을 보존하고자 한다면 확장용 종료일(`EndDate`)을 오늘로 지정하고 새로운 단가를 가진 신규 BOM 행을 생성하는 버전 관리가 추후 가능합니다. (현재는 단일 행 `UPDATE` 형태로 단순 수정 처리합니다.)
- 3.2.3. **삭제:** 특정 품목 구성을 삭제 시 `RecodingState` 값을 `0`으로 업데이트하여 소프트 삭제합니다.

## 4. 화면 (UI/UX) 구성안
- 4.1. **좌측 영역 (모품목 계층 트리):** 품목 마스터 중 '제품' 및 '반제품'만 목록에 표시하며, 특정 품목을 클릭하면 하위 BOM 전개(Explosion)[^2] 구조를 트리(Tree) 형태로 즉시 시각화하여 구조를 입체적으로 보게 만듭니다.
- 4.2. **우측 영역 (자품목 그리드 & 편집 폼):** 
  - 상단에는 선택된 모품목의 기본 제원(규격, 단위)을 읽기 전용 칩으로 보여줍니다.
  - 중앙에는 매핑된 자품목들의 목록(코드, 명칭, 소요량 분자, 분모)이 표출되는 테이블 그리드가 위치합니다.
  - 하단에는 신규 자품목을 검색하여 즉시 리스트에 추가하고 소요 수량을 등록하는 모던한 폼 컴포넌트가 배치됩니다.
