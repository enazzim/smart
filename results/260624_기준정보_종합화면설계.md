## 1. 개요
ERP 기준정보는 일관되고 직관적인 인터페이스를 제공하여 현업 사용자의 입력 오류를 최소화하고 데이터 관리 생산성을 극대화해야 합니다. 본 설계는 ERP 기준정보 10대 종류의 공통 화면 구성 레이아웃 패턴과 각 종류별 세부 화면 설계안을 다룹니다.

## 2. 공통 UI/UX 레이아웃 패턴
대부분의 기준정보 화면은 **'2분할 마스터-디테일(Split master-detail) 패턴'**을 기본 아키텍처로 사용하며, 일부 계층 구조가 필요한 화면은 **'트리-그리드(Tree-Grid) 패턴'**을 적용합니다.
- 2.1. **2분할 패턴:** 좌측 영역에 검색 필터와 데이터 목록(Grid)을 두고, 특정 행 선택 시 우측 영역에 상세 입력/편집 폼(Form)을 배치하여 화면 전환 없이 입력 작업을 수행합니다.
- 2.2. **트리-그리드 패턴:** BOM이나 공정순서처럼 상/하위 관계가 뚜렷한 경우, 좌측에 계층형 트리 뷰를 두고 우측에 관련 상세 테이블을 매핑하여 가독성을 높입니다.

## 3. 기준정보 종류별 화면 구성 설계안

### 3.1. 공용코드 정보 화면
- 3.1.1. **좌측 영역 (대분류 목록):** 대분류코드 및 명칭을 리스트 그리드로 조회하고 선택합니다.
- 3.1.2. **우측 영역 (소분류 상세 및 편집 폼):** 선택한 대분류에 매핑되는 하위 소분류 목록을 그리드로 보여주고, 상단에 대/소분류의 추가/수정/소프트삭제 입력 폼을 배치합니다.

### 3.2. 거래처 정보 화면
- 3.2.1. **좌측 영역 (거래처 목록):** 검색 바(거래처명/사업자번호)와 다중 역할 칩 필터(수주/구매 등)를 제공하며, 매핑된 구분은 태그 배지 형태로 요약 표출합니다.
- 3.2.2. **우측 영역 (상세 정보 폼):** 다이어트된 필수 7대 필드를 2열 배치하고, 거래처 역할 선택은 클릭식 멀티 셀렉트 칩으로 구성합니다. (실적 조회를 위한 현황 메뉴 바로가기 링크 제공)

### 3.3. 품목 정보 화면
- 3.3.1. **좌측 영역 (품목 목록):** 품목번호/품목명 검색 및 자산분류별(제품/반제품/원자재) 탭 필터를 배치합니다.
- 3.3.2. **우측 영역 (상세 정보 폼):** 11대 필수 필드를 입력하고, '자산분류' 변경 시 기본 창고가 최적의 추천 창고로 자동 선택되는 드롭다운 UI를 적용합니다.

### 3.4. 품목구성 (BOM) 화면
- 3.4.1. **좌측 영역 (모품목 계층 트리):** 제품 및 반제품의 BOM 관계를 트리 구조로 시각화하여 접고 펼칠 수 있게 제공합니다.
- 3.4.2. **우측 영역 (자품목 구성 및 소요량 Grid):** 선택한 모품목에 포함되는 자품목 목록과 정미 소요량, 로스율 등을 등록 및 수정하는 양방향 연결 폼입니다.

### 3.5. 작업장 정보 화면
- 3.5.1. **좌측 영역 (작업장 목록):** 공장 내 설치된 작업장(Work Center) 명칭 및 가동 유무 상태를 그리드로 표시합니다.
- 3.5.2. **우측 영역 (상세 폼):** 작업장 코드, 명칭, 소속 부서, 일일 기본 가동시간 등을 정의하는 세부 폼입니다.

### 3.6. 공정순서 화면
- 3.6.1. **좌측 영역 (품목 목록):** 라우팅 공정 조회의 대상이 되는 반제품 및 완제품 목록을 조회합니다.
- 3.6.2. **우측 영역 (공정 순서 그리드 및 상세 편집):** 
  - 등록된 공정들이 정렬되어 표출되며, 상세 편집 폼에서 **'작업구분'**(`WorkDivision`) 선택에 따라 동적 필드 제어가 이루어집니다.
  - **'자가' 선택 시:** 작업장(`WCIndex`) 선택 드롭다운 활성화(필수), 외주 리드타임 및 외주 발주비율 비활성화.
  - **'외주' 선택 시:** 외주 리드타임 입력칸 활성화(필수, 일 단위), 작업장 선택 및 외주 발주비율 비활성화.
  - **'자가/외주' 선택 시:** 작업장, 외주 리드타임, 외주 발주비율(`OutsourceRate`) 입력칸 **모두 활성화(필수)**.
  - 나중에 '작업계획 수립' 시 자가/외주인 공정은 외주 발주비율에 따라 자가 지시 수량과 외주 지시 수량으로 자동 분할(예: 200개 지시 시 발주비율 40%이면 자가 120개, 외주 80개로 자동 분할 수립)된다는 안내 문구를 편집 폼 하단에 상시 표출하여 작업자의 직관적인 이해를 돕습니다.

### 3.7. 설비 정보 화면
- 3.7.1. **좌측 영역 (설비 목록 그리드):** 
  - 설비분류 필터와 통합 검색 바를 제공하여 설비를 검색합니다.
  - 설비 그리드 컬럼은 `설비번호`, `설비명`, `설비분류`, `사용 작업장`, `설비 수명 진행률`로 구성합니다.
  - **수명 진행률 게이지 바(ProgressBar):** `(누계 샷 / 설계 샷) * 100`으로 계산된 수치적 게이지 바를 컬러(정상: 녹색, 교체 임박: 적색)로 표현하여 사용자 시각 인지성을 강화합니다.
- 3.7.2. **우측 영역 (상세 정보 폼):** 
  - 필수 필드인 `설비번호`, `설비명`, `설비분류`, `설계 샷`, `초기 샷`을 간결하게 배치합니다.
  - `작업 샷`과 `누계 샷` 필드는 읽기 전용(Read-only, 회색) 필드로 두어 조회만 가능하게 제한하고 시스템이 누적 계산하도록 지원합니다.
  - 작업장 연결 드롭다운 콤보박스는 공장 내 마스터 작업장(`WCI_MT`)을 안전하게 선택하도록 구성합니다.

### 3.8. 작업표준 정보 화면
- 3.8.1. **좌측 영역 (품목-공정 트리 그리드):** 
  - 등록 대상인 자가 및 자가/외주 공정이 배정된 품목 목록을 트리-그리드 형태로 제공합니다.
  - 품목 노드를 확장하면 해당 품목에 매핑된 자가 공정 목록이 나타나고, 이를 클릭하여 우측 상세 폼을 활성화합니다.
- 3.8.2. **우측 영역 (상세 정보 및 셋업 폼):** 
  - 필수 필드인 작업장, 사용설비, 주작업자, 우선순위, 셋업 시간(분 단위 정수), 표준 가공 시간(초 단위 정수), 사용공구명을 입력하는 편집 영역입니다.
  - 작업장, 사용설비, 주작업자 필드는 각각 마스터 정보로부터 바인딩된 안전한 셀렉트 드롭다운 UI로 제공됩니다.
  - 현업 사용자의 입력 혼선을 막기 위해 각 시간 필드 옆에 명확한 단위 표시 `(분)`, `(초)`를 제공합니다.

### 3.9. 단가 정보 화면 (수주 / 구매 / 외주 통합)
- 3.9.1. **좌측 영역 (단가 구분 탭 및 품목 리스트 그리드):** 
  - 상단에 '구매단가', '판매단가', '외주단가'의 3대 탭 제어기를 배치합니다.
  - 선택한 탭에 맞춰 등록된 단가 목록(품목정보, 거래처, 기준단가, 발주비율, 유효기간 등)을 그리드로 조회합니다.
- 3.9.2. **우측 영역 (상세 편집 폼 및 단가 변경 히스토리):** 
  - 단가 구분 탭 선택 상태에 따라 입력 폼이 유기적으로 변경됩니다.
  - **'구매단가' 선택 시:** 거래처 및 발주비율(%) 입력칸 활성화, 시작공정/종료공정 드롭다운 비활성화.
  - **'판매단가' 선택 시:** 거래처 입력칸만 활성화, 발주비율 및 시작공정/종료공정 비활성화.
  - **'외주단가' 선택 시:** 거래처, 발주비율, 시작공정/종료공정 드롭다운 **모두 활성화(필수)**.
  - 하단 타임라인 영역에는 해당 계약의 유효일자별 단가 변경 히스토리 그리드가 제공되며, 단가 수정 시 '변경 사유' 입력을 강제하여 이력을 투명하게 관리합니다.

### 3.10. 사용자 정보 화면
- 3.10.1. **좌측 영역 (사원 목록 그리드):** 
  - 부서 및 사용권한별 필터와 통합 검색 바를 제공하여 사원을 검색합니다.
  - 그리드 컬럼은 `아이디`, `이름`, `연락처`, `사용권한`, `업무일지그룹`으로 구성합니다.
- 3.10.2. **우측 영역 (상세 편집 및 권한 폼):** 
  - 필수 필드인 아이디, 비밀번호, 이름, 사용권한과 선택 필드인 연락처, 업무일지그룹, 이메일을 입력하는 폼입니다.
  - 사용권한과 업무일지그룹은 공용코드(`PUC_MT`)에서 가져온 드롭다운 선택상자(콤보박스) UI를 적용합니다.
  - 비밀번호 입력 시 보안 가이드 라인(예: 8자리 이상 등)에 부합하는지 프론트엔드에서 실시간 유효성 체크 피드백을 노출합니다.

### 3.11. 기본생산달력 화면
- 3.11.1. **메인 영역 (대형 기본 캘린더):**
  - 화면 전체에 월별 기본생산달력을 크게 보여주고, 각 날짜 칸 내에 설정된 작업시간(예: "8h", "휴무")을 시각적으로 표출합니다.
  - 특정 일자를 클릭하여 상세 설정 모달(가동시간 입력란, 비고란)을 호출하고 등록 및 수정할 수 있게 구성합니다.

### 3.12. 작업장별 생산달력 화면
- 3.12.1. **좌측 영역 (작업장 목록):** 공장 내 등록된 마스터 작업장(`WCI_MT`) 목록을 조회하고 선택합니다.
- 3.12.2. **우측 영역 (예외 조정 캘린더):** 
  - 좌측에서 선택한 작업장의 개별 예외 캘린더를 크게 노출합니다.
  - 기본생산달력 대비 변경이 필요한 특정 일자를 클릭하여 가동시간을 조정(예: 특근 12h, 정비 0h 등)합니다.
  - 조정된 날짜는 캘린더 상에 주황색 배경 등의 하이라이트 UI로 표현하여 기본 달력 설정과 즉각 구별되도록 돕습니다.

> [!important] 일관성 유지를 위한 UI 가이드라인
> 모든 등록 화면에는 동일한 규격의 [초기화(신규)], [저장(등록/수정)], [삭제] 공통 버튼 바를 동일한 우측 상단 위치에 노출하여 조작 동선을 통일시킵니다.
