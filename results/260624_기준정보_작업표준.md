## 1. 개요
작업표준정보(Operation Standard)는 자가 생산 공정별로 작업장, 사용 설비, 작업자, 공구 등 표준 작업 조건을 매핑하고 이에 소요되는 기준 시간(셋업 시간, 표준 가공 시간)을 정의하는 기준 마스터 정보입니다. 이는 원가 계산의 기초 데이터가 될 뿐만 아니라, 생산 계획 및 일정 수립(Scheduling) 단계에서 소요 일수를 산출하는 결정적인 데이터 역할을 수행합니다.

## 2. 데이터베이스 설계안 (WSI_MT)
외래키 식별 대원칙에 따라 모든 마스터 참조 컬럼을 정수형 기본키(`Index`) 매핑으로 구조화하였으며, 부적합했던 DATETIME 형태의 시간 컬럼을 논리적인 정수 타입(초/분)으로 전면 전환하였습니다.

### 2.1. 작업표준 마스터 테이블 (WSI_MT)
| 컬럼명 | 데이터 타입 | Null 여부 | 속성 및 용도 |
|---|---|---|---|
| `Index` | `INT` | NOT NULL | 고유 식별 일련번호 (PK, AUTO_INCREMENT) |
| `ItemIndex` | `INT` | NOT NULL | 대상 품목 식별 인덱스 (FK, II_MT 참조) |
| `ProcessIndex` | `INT` | NOT NULL | 적용 공정 식별 인덱스 (FK, 공용코드 PUC_MT 참조) |
| `WCIndex` | `INT` | NOT NULL | 작업장 식별 인덱스 (FK, WCI_MT 참조) |
| `EquipmentIndex` | `INT` | NULL | 사용설비 식별 인덱스 (FK, EI_MT 참조, 미매핑 시 NULL 허용) |
| `Priority` | `INT` | NOT NULL | 작업 우선순위 (1순위, 2순위 등 우선 적용 판정용) |
| `MainWorkerIndex` | `INT` | NULL | 주작업자 사원 식별 인덱스 (FK, UI_MT 참조, 미지정 시 NULL 허용) |
| `ToolName` | `VARCHAR(255)` | NULL | 사용 공구명 |
| `SetupTime` | `INT` | NOT NULL | 기계 준비 및 셋업 시간 (단위: 분, 기본값 0) |
| `StandardTime` | `INT` | NOT NULL | 개당(또는 기준단위당) 생산 소요 시간 (단위: 초, 기본값 0) |
| `RecodingState` | `TINYINT(1)` | NOT NULL | 레코드 제어 상태 (소프트 삭제용 플래그, 기본값 1) |
| `RegistrationPerson` | `VARCHAR(255)` | NOT NULL | 등록자 |
| `RegistrationDate` | `DATETIME` | NOT NULL | 등록일시 |
| `UpdatingPerson` | `VARCHAR(255)` | NULL | 수정자 |
| `UpdatingDate` | `DATETIME` | NULL | 수정일시 |

> [!important] 외래키(FK) 무결성 및 인덱스
> - 모든 외래키 컬럼(`ItemIndex`, `ProcessIndex`, `WCIndex`, `EquipmentIndex`, `MainWorkerIndex`)에 대해 물리 인덱스를 구성하여 조회 성능을 강화했습니다.
> - 사원 정보는 레거시의 단순 텍스트(`MainWorkerID`) 형태에서 정규화된 사원 마스터 테이블(`UI_MT`)의 기본키를 지향하도록 구성했습니다.

## 3. 핵심 비즈니스 로직 및 제약 사항

### 3.1. 등록 대상 공정 필터링 규칙
- 3.1.1. **자가 공정 한정 규칙:** 작업표준은 우리 기업 내부에서 처리하는 공정만을 대상으로 합니다. 따라서 작업구분(`WorkDivision`)이 **'자가'** 또는 **'자가/외주'**로 지정된 공정만 등록이 가능하며, 순수 '외주' 공정은 작업표준 등록 대상에서 배제합니다.

### 3.2. 일정 스케줄링 및 Capa 기반 리드타임 연산
- 3.2.1. **소요 시간 연산 공식:** 특정 작업지시 수량($Q$)에 대한 총 소요 시간($T$, 단위: 초)은 아래와 같이 연산됩니다.
  $$T = (\text{SetupTime} \times 60) + (\text{StandardTime} \times Q)$$
- 3.2.2. **예시 시나리오:** 표준시간 10초, 셋업시간 10분(600초)인 공정에서 400개 작업을 수행하는 경우.
  - 총 소요 시간: $600\text{초} + (10\text{초} \times 400) = 4,600\text{초}$ (약 76.6분)
  - 이 소요 시간을 토대로 해당 작업장의 일일 가동시간 및 투입인원(Capa)과 비교하여 생산 스케줄링 엔진이 며칠의 리드타임이 소요될지(예: 0.2일 소요 등) 달력 상에 일정을 자동 배치합니다.

### 3.3. 동일 공정 다중 매핑과 우선순위 룰
- 3.3.1. **다중 표준 등록 허용:** 동일한 품목의 동일 공정이더라도 가동하는 작업장, 사용 설비, 혹은 주작업자의 숙련도에 따라 여러 개의 작업표준 레코드를 등록할 수 있습니다.
- 3.3.2. **우선순위 자동 선택:** 생산 일정 수립 시, 시스템은 여러 표준안 중 **우선순위(`Priority`) 값이 가장 낮은(즉, 1순위에 가까운) 레코드를 기본 가동 조건**으로 채택하여 소요 일수를 연산합니다.

## 4. 화면 (UI/UX) 구성안 (2분할 마스터-디테일 패턴)
사용자가 작업 대상 공정을 먼저 직관적으로 선택하고 표준 사양을 입력할 수 있도록 통일된 패턴을 제공합니다.

### 4.1. 좌측 영역 (품목-공정 트리 그리드)
- 4.1.1. 자가/자가외주 공정이 존재하는 품목 목록을 트리 구조로 노출합니다.
- 4.1.2. 품목 노드를 펼치면 하위에 배정된 자가 생산 공정 목록이 나타나며, 특정 공정을 선택하면 우측 편집 폼에 상세 항목이 로드됩니다.

### 4.2. 우측 영역 (작업표준 상세 및 편집 폼)
- 4.2.1. **기준정보 연동 콤보박스:** `작업장`, `사용설비`, `주작업자` 필드는 각각 마스터 테이블(`WCI_MT`, `EI_MT`, `UI_MT`)로부터 활성 데이터를 바인딩하여 안전한 드롭다운 선택 UI로 제공합니다.
- 4.2.2. **우선순위 입력 필드:** 숫자로 입력받으며 기본값은 1로 세팅됩니다.
- 4.2.3. **수치형 입력 필드 단위 가이드:** 셋업 타임 입력칸 뒤에는 `(분)` 단위를, 표준 가공 시간 입력칸 뒤에는 `(초)` 단위를 명확하게 명시하여 현업의 데이터 오입력을 원천 방지합니다.
