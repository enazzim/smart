## B. P0 — 거래처 ([`d4-company.md`](./d4-company.md) v0.3)

**배경:** 레거시 36필드 → 슬림 + `company_role` 4종 + `partner_ledger_*`

### B1. Drop 필드 (신규 화면 없음)

| Drop 항목 (레거시) | 현업 질문 |
|-------------------|-----------|
| `TaxBillAddress` (세금계산서 주소) | 사업장주소와 별도로 꼭 필요한가요? |
| `CurrentTradeState` (거래상태) | 거래중/중단을 마스터에서 관리하시나요? |
| `SupplementaryValueTax`, `Rate` | 거래처 마스터가 아닌 전표/품목에서 처리해도 되나요? |
| `TradeClassification1~3` | **PUC 분류 3개 완전 제거**해도 되나요? |
| `SaleStandardBillDate` | 매출기준일만으로 충분한가요? |
| `FixPeriodCollectMoneyDate2` | 정기수금일 1개만 유지해도 되나요? |

**종합:** Drop 9개 중 **반드시 살려야 할 필드**가 있나요? (필드명·용도 기재)

### B2. 역할·원장

| # | 설계 | 질문 | 동의 |
|---|------|------|:----:|
| B2-1 | 판매/구매/외주/비용 체크 4종, **최소 1개 필수** | `CI_MT` 4 boolean과 동일한가요? COST만 거래처가 있나요? | |
| B2-2 | `SALES` → 매출 원장 account 자동 생성 (금액 0) | 등록 시 원장 **껍데기만** 만들어도 되나요? | |
| B2-3 | `PURCHASE` + `OUTSOURCE` → **매입 원장 1개 공유** | 외주도 구매 원장에 합쳐도 되나요? | |
| B2-4 | `COST`만 단독 → 원장 **미생성** | 비용 전용 거래처는 마스터만 두어도 되나요? | |
| B2-5 | BSI 72컬럼 → `partner_ledger_monthly` 12행 | 미수·미지급을 월별 합계로 보면 되나요? (등록 화면에서 월별 입력 없음) | |
